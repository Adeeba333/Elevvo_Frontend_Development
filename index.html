Publications

Rice MultiNet: A Hybrid Deep Learning Feature-Fusion Model for Multi-Class Rice Leaf Disease Identification with Explainable AI and Web Deployment

Published:IEEE|April 2026

Rice MultiNet is a hybrid deep learning model designed to identify multiple rice leaf diseases accurately from leaf images. It combines features from different deep learning networks using feature fusion to improve classification performance. The model supports multi-class detection of diseases such as Bacterial Leaf Blight, Brown Spot, Leaf Blast, Leaf Scald, Narrow Brown Spot, and Healthy leaves. Explainable AI (XAI) techniques are used to show which parts of the leaf influenced the model's prediction, making the results easier to understand. The system is also deployed through a web application, allowing users to upload rice leaf images and receive disease predictions.

For more details, please visit the IEEE Xplore.
